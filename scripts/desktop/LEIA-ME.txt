SISTEMA DE CONTROLE - VERSÃO DESKTOP
====================================

COMO USAR
1. Extraia esta pasta inteira para um local seu, por exemplo:
   C:\SistemaDeControle   ou   Documentos\SistemaDeControle
   (evite "C:\Arquivos de Programas", que não permite gravação)
2. Dê dois cliques em SistemaDeControle.exe.
   - Se o Windows mostrar "O Windows protegeu o computador", clique em
     "Mais informações" > "Executar assim mesmo" (o programa não é assinado digitalmente).
   - Se o Firewall perguntar, pode negar o acesso à rede: o sistema só é usado neste computador.
3. Na PRIMEIRA execução, a janela pede o e-mail e a senha da conta de administrador.
   Guarde essa senha.
4. O navegador abre sozinho em http://localhost:5080
5. Mantenha a janela preta aberta enquanto usa o sistema. Para encerrar, feche-a.

ESQUECI A SENHA
Dê dois cliques em "Redefinir senha do administrador.bat" e digite uma nova senha.
(ou rode no terminal: SistemaDeControle.exe --redefinir-senha)
A conta de administrador sempre é recriada automaticamente se for apagada.

ONDE FICAM OS DADOS
%LOCALAPPDATA%\SistemaDeControle
  banco\        banco de dados PostgreSQL
  anexos\       atestados enviados
  config.json   configuração gerada na primeira execução
  postgres.log  log do banco (útil se algo der errado)

BACKUP
Feche o sistema e copie a pasta %LOCALAPPDATA%\SistemaDeControle inteira para um
pendrive ou nuvem. Para restaurar, feche o sistema e coloque a pasta de volta.

ATUALIZAR PARA UMA NOVA VERSÃO
Feche o sistema, substitua a pasta do programa pela nova e abra de novo.
Os dados não são apagados (ficam em %LOCALAPPDATA%).
